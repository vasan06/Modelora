Algorithms

Algorithm types explained for beginners

Selected Algorithm

Click any algorithm name

Select an algorithm from the cards below to see when to use it, what problem it solves, and how a beginner can understand it.

Regression

Use regression when the answer is a number, such as price, marks, temperature, salary, or sales prediction.

Linear Regression Finds a straight-line relationship between input and output.
Ridge Regression Improves linear regression when many features affect the result.
Lasso Regression Selects important features and reduces unnecessary ones.
Decision Tree Regression Splits data using rule-based decisions.
Random Forest Regression Uses many decision trees for stronger numeric prediction.
KNN Regression Predicts using nearby similar data points.

Classification

Use classification when the answer is a category, such as pass or fail, spam or not spam, disease or no disease, or product type.

Logistic Regression Predicts probability of a class, such as yes or no.
Decision Tree Classification Creates rule-based class decisions.
Random Forest Classification Combines many trees to reduce wrong classification.
KNN Classification Checks nearby examples and chooses the most common class.
Naive Bayes Works well for text, spam detection, and probability-based problems.

Clustering

Use clustering when there is no target column and you want the system to find natural groups in data.

K-Means Groups data into K clusters based on similarity.
Hierarchical Clustering Builds cluster groups step by step like a tree structure.

Dimensionality Reduction

Use this when the dataset has many columns and you want to simplify it while keeping important information.

PCA Compresses many features into fewer meaningful components.

Semi-Supervised Learning

Use this when only some rows have labels and the remaining rows are unlabelled.

Label Propagation Spreads known labels to similar unlabelled data points.

Reinforcement Learning

Use this to understand how an agent learns by trying actions and receiving rewards or penalties.

Q-Learning Teaches an agent which action gives the best long-term reward.

Beginner Guide

How to choose the correct algorithm

Need to predict a number?

Use regression. Example: predict house price, student marks, salary, or sales amount.

Need to predict a label?

Use classification. Example: spam or not spam, pass or fail, disease or no disease.

No target column?

Use clustering. Example: group customers, products, or similar data points.

Too many columns?

Use PCA. It reduces features and helps visualize complex datasets.

Only some labels available?

Use semi-supervised learning. It learns from labelled and unlabelled data together.

Agent learns from rewards?

Use reinforcement learning. It is useful for action-based learning demos.
